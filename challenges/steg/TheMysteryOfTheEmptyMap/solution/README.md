# The Mystery Of The Empty Map

## Write-up

Il y a des espaces et tabulations, on peut le remarquer en selectionnant le texte dans un editeur comme Visual Code par exemple. Il n'y a pas vraiment d'indice pour savoir ce que ca signifie, mais avec essai et erreur on peut mettre les espaces en 0 et les tabulations en 1 puisqu'il y a 8 caracteres par lignes. En decodant le binaire, on obtient le flag.
