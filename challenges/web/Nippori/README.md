# Nippori

**`Otaphoque`**

## Description

Vous êtes en visite au Japon pour découvrir le monde merveilleux du textile... Ah, toutes ces soieries toutes plus soyeuses les unes que les autres, ces cotons imprimés aux couleurs vibrantes et aux motifs géométriques si caractéristiques du pays du soleil levant, et ce lin plus naturel que la nature elle-même ! Bref, vous ne savez pas par où commencer. Heureusement que ce site existe pour vous aiguiller dans votre aventure textile!
